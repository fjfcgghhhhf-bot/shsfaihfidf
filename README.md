# ORBIT

Сетевая игра для четырёх участников, готовая для Render. Node.js 22+, без внешних зависимостей.

## Запуск

`npm ci`, затем `npm start`. Откройте http://localhost:3000.

Проверки: `npm test`.

## Render

Загрузите содержимое этой папки в корень GitHub-репозитория. В Render выберите New → Blueprint и этот репозиторий: настройки находятся в render.yaml. Или создайте Web Service: runtime Node, build command `npm ci`, start command `npm start`, health check `/health`.

Используйте ровно один экземпляр сервера: состояние общей игры хранится в памяти, перезапуск обнуляет игру. Сервер слушает 0.0.0.0 и переменную PORT. Документация: https://render.com/docs/web-services и https://render.com/docs/blueprint-spec.

## Правила

- Первые четыре подключений автоматически начинают игру, остальные ждут. Лобби нет.
- Перед каждым этапом — отсчёт 3,5 секунды, затем сигнал. Первое нажатие нужно сделать в течение 5 секунд после сигнала; все остальные — в течение одной секунды после первого.
- Раннее нажатие, пропуск и отключение участника сбрасывают все шесть этапов. Повторные запросы уже нажавшего участника игнорируются.
- После шестого этапа три случайных участника получают разные коды: 345231, 820935, 147983. Сервер отправляет код только его получателю.
- Через 30 секунд результат очищается; если участников достаточно, начинается следующая игра.
- После победы сыгравшие участники переходят в конец очереди, ожидающие входят в следующий экипаж. Одна вкладка считается одним участником. Проверки уникальности человека нет.
- При обрыве соединения браузер подключается заново как новый участник. Полученный код следует скопировать до закрытия страницы.

Коды можно заменить переменной окружения `REWARD_CODES` (три шестизначных кода через запятую). Эти коды повторяются в каждой игре; это не система одноразовых купонов. Для секретных кодов используйте переменную Render, а не публичный репозиторий.
